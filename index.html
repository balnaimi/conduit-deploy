Everything you need

One script sets up a production-ready messaging server

🔒

End-to-End Encryption

Messages are encrypted on your device. Nobody — not even the server — can read them.

📞

Voice & Video Calls

Built-in TURN/STUN server for calls that work across networks, NATs, and firewalls.

🌐

Federation

Talk to anyone on the Matrix network — millions of users on thousands of servers.

🔐

Auto TLS

Let's Encrypt certificates handled automatically by Caddy. Zero maintenance.

🛡️

Hardened by Default

Firewall, fail2ban, auto-updates, and Docker network isolation — all configured for you.

⚡

Lightweight

Conduit (Rust) uses ~50MB RAM. Runs great on a $5/month VPS with 512MB RAM.

Up and running in 4 steps

From zero to messaging in about 30 minutes

1

Get a server

Any VPS with 512MB RAM. Hetzner, DigitalOcean, or even Oracle's free tier.

2

Point your domain

Add a DNS record pointing to your server. The script tells you exactly what to add.

3

Run the script

One command. Interactive menu guides you through everything. No config files to edit.

4

Start chatting

Download Element (or any Matrix app), sign in, invite your people. Done!
